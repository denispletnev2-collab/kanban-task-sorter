# Kanban Task Sorter

Плагин для [Obsidian](https://obsidian.md), который копирует невыполненные
задачи (`- [ ] ...`) из любых заметок хранилища в две канбан-доски:

- без даты → лейн **Sort** файла `Жизнь.md`
- с датой (📅 ⏳ 🛫 🔁) → лейн **Sort** файла `Датируемые.md`

Исходные заметки не изменяются — задачи остаются на месте, в доски
копируется только их текст.

## Возможности

- **Два режима сканирования**
  - иконка на боковой ленте — сканирует только текущий открытый файл
  - команда «Разобрать задачи по доскам» — полный скан хранилища, с кэшем
    (пропускает файлы, не менявшиеся с прошлого скана)
- **Двойная защита от дублей**
  - кэш уже скопированных задач по каждому файлу-источнику
  - дополнительная проверка по содержимому целевого файла на случай сброса
    кэша или одинаковой задачи в двух заметках
- **Настраиваемые пути** к файлам-доскам, название лейна-приёмника,
  список исключённых папок
- Вложенные подзадачи и уже выполненные задачи (`- [x]`) не трогаются

## Установка

### Вручную

1. Скачайте `main.js` и `manifest.json` из последнего
   [релиза](../../releases/latest)
2. Создайте папку `<ваше_хранилище>/.obsidian/plugins/kanban-task-sorter/`
   и положите туда оба файла
3. Перезапустите Obsidian → Настройки → Сторонние плагины → включите
   **Kanban Task Sorter**

### Через BRAT

Если у вас установлен [BRAT](https://github.com/TfTHacker/obsidian42-brat),
можно добавить этот репозиторий напрямую по ссылке — плагин не обязан быть
в официальном каталоге Obsidian для установки через BRAT.

## Настройка

После включения откройте настройки плагина и укажите:

- **Файл без даты (Sort)** — путь к `Жизнь.md` от корня хранилища
  (например, `Дневник/Задачи/Kanban доски/Жизнь.md`)
- **Файл с датой (Sort)** — путь к `Датируемые.md`
- при необходимости — название лейна-приёмника (по умолчанию `## Sort`),
  исключённые папки, и переключатель «только задачи верхнего уровня»

## Как определяется «дата»

Задача считается датированной, если в тексте есть один из эмодзи-маркеров
плагина [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks):
📅 (срок), ⏳ (запланировано), 🛫 (старт), 🔁 (повтор), ➕ (создано).

## Разработка

```bash
npm install
node esbuild.config.mjs   # соберёт main.js
```

Пуш тега (например `git tag 1.0.1 && git push --tags`) запускает GitHub
Actions, который собирает `main.js` и прикладывает его вместе с
`manifest.json` к новому релизу.
